The code here is an independent implementation. Original authors retain rights in their original materials. No blanket license is asserted for source repositories whose license was not identified. Consult the source authors before importing their code or republishing their data. The historical notebook, helper functions, benchmark fit/evaluator and model implementation were inspected for concepts and contracts, not copied into this repository.

`datasets/public` is generated by `higgslab generate datasets/public --seed 42 --mu 1 --beta 1`. Its events are synthetic toy kinematics; expected yields are pedagogical choices (350 signal and 1600 background), not cross-section predictions. It contains no copied detector events. Regenerate it with the pinned environment and verify `checksums.json`. The generator returns truth to its trusted caller rather than writing it into input directories. The public truth is mu=1, beta=1, mH=125 GeV.

The optional ROOT preparation command converts MeV to GeV, takes massless lepton/jet approximations, preserves source row IDs, filters positive weights and exactly two leptons, and partitions before resampling. The source ROOT file is not redistributed here. ATLAS Open Data attribution, original release/license and derivation should accompany any real sample an instructor elects to redistribute; this implementation does not establish that provenance on their behalf.

## Deliberate migration from the workshop contract

The small synthetic default makes a clean checkout usable without a second repository and without silently redistributing ambiguously licensed artifacts. It changes the physics distributions and expected yields; historical benchmark scores cannot be compared. Explicit partitions prevent training/templates/data overlap. JSON weights remain the portable model format. Runtime includes the trusted HiggsLab package in the evaluator image. The local score uses all positive injected cases rather than a truth-significance threshold; see the versioned score contract. There is no claim that short toy pretraining produces a general collider foundation model.
