# HiggsLab: From Events to Evidence

Build a Higgs-to-WW measurement with machine learning and a statistical fit.

**Created by [Gordon Watts](https://github.com/gordonwatts) and [Andrzej Novak](https://github.com/andrzejnovak).** HiggsLab grows out of the [2026 HSF-India Delhi workshop](https://indico.cern.ch/event/1714663/timetable/#sc-15-2-mlai), its [machine-learning course materials](https://github.com/gordonwatts/courses-hsf-india-October2026), and the [H→WW benchmark kit](https://github.com/andrzejnovak/hsf-india-hww). The complete tutorial will acknowledge other contributors alongside the material it reuses.

The tutorial is in the planning stage. See [plan.md](plan.md) for the student paths, repository design, instructor setup strategy, evaluator, documentation site, and build sequence.
